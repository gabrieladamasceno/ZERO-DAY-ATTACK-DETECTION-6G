# ZERO-DAY-ATTACK-DETECTION-6G
Sixth-generation (6G) networks are being developed as a new paradigm for mobile communication systems and are primarily characterized by the integration of Artificial Intelligence (AI) techniques and sustainability, which in this context is directly related to the allocation of computational resources. However, this evolution also expands the surface area for cyberattacks, making communication environments more susceptible to sophisticated threats, especially Zero-Day attacks, which exploit vulnerabilities that are still unknown to network security systems, including AI models. In this sense, anomaly detection mechanisms based on AI and Machine Learning (ML) become essential to ensure the security and reliability of future networks. However, selecting an IA/ML model to compose a a solution for zero-day attack detection is a challenge, as it is necessary to achieve high detection accuracy but without overconsumption of computational resources or getting impractical time to detect the attacks. In this sense, this work addresses the use of supervised machine learning models in the detection of Zero-Day attacks in datasets from advanced 5G mobile networks (5GA). Five models widely used in the literature, Multilayer Perceptron (MLP), Autoencoder, Random Forest, Decision Tree, and CatBoost, were evaluated using simultaneously performance metrics such as accuracy, precision, recall, and F1-score, as well as metrics for allocating computational resources such as CPU and memory consumption, execution time, and energy consumption estimates, which are critical factors in 6G networks. The results indicate that complex models like CatBoost can exhibit high predictive capacity, but architectures based on Decision Trees appear to be the most promising for real-time implementation, as they deliver a convincing detection rate with significantly lower energy and processing consumption.
